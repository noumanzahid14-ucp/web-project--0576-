# PIXELS & POWER 🎮

### Power Your Game. Own Your World.

## 1. Project Overview

**Pixels and Power** is a gaming accessories e-commerce themed website developed as part of the Web Technologies Project 1.

The website showcases different gaming accessories, including gaming mice, keyboards, headsets, mousepads, monitors and RGB PC cases.

The website is designed using a black and neon green color theme to give it a modern gaming look.

## 2. Project Theme

- **Website Name:** Pixels and Power
- **Theme:** Gaming Accessories E-Commerce
- **Color Scheme:** Black and Neon Green
- **Technologies:** HTML5 and CSS3
- **Code Editor:** Visual Studio Code
